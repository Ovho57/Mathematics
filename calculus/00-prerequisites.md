# 00 — Prerequisites: Strengthen the Foundation

Calculus uses algebra constantly. If algebra feels hard, take time here first—this is normal and fixable.

## Powers and exponents

\[
x^a x^b=x^{a+b},\quad (x^a)^b=x^{ab},\quad x^{-n}=\frac1{x^n}
\]

For nonzero (x), (x^0=1).

## Factorization

\[
x^2-9=(x-3)(x+3)
\]

Factoring often helps simplify limits.

## Solving equations

Solve (2x+5=13):
\[
2x=8\Rightarrow x=4
\]

Keep equations balanced: apply the same operation to both sides.

## Functions

A function assigns an output to an input. If (f(x)=2x+1), then:
\[
f(3)=2(3)+1=7
\]

## Slope

For points ((x_1,y_1)) and ((x_2,y_2)):
\[
m=\frac{y_2-y_1}{x_2-x_1}
\]

Slope measures vertical change per horizontal change.

## Quick check

1. Simplify (x^3x^4).
2. Factor (x^2-16).
3. Solve (3x-7=11).
4. If (f(x)=x^2+2), find (f(3)).
5. Find the slope from ((1,2)) to ((4,8)).

**Answers:** (x^7); ((x-4)(x+4)); (x=6); (11); slope (2).

Also review fractions, negative numbers, graphs, trigonometry, exponentials, and logarithms when needed.
