# 07 — Integration: Accumulation and Area

Integration adds many small contributions and reverses differentiation.

## Indefinite integral

If (F'(x)=f(x)), then:
\[
\int f(x)dx=F(x)+C
\]

The (+C) is necessary because the derivative of a constant is zero.

## Reverse power rule

For (n\ne-1):
\[
\int x^n dx=\frac{x^{n+1}}{n+1}+C
\]

Example:
\[
\int3x^2dx=x^3+C
\]

## Definite integral

\[
\int_a^b f(x)dx
\]

represents signed accumulation. Values above the x-axis contribute positively; below contribute negatively.

## Fundamental Theorem of Calculus

If (F'=f):
\[
\int_a^b f(x)dx=F(b)-F(a)
\]

Example:
\[
\int_0^2 2x dx=[x^2]_0^2=4
\]
