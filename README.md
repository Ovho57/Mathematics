# Mathematics — From Foundations to Mastery

A growing, multi-topic mathematics textbook repository. It is designed to help learners build understanding from the basics, develop exam-solving skills, and apply mathematics to real-world problems.

## Start here

Choose a topic folder and begin with its README. Follow lessons in order, solve examples yourself, then attempt practice questions without looking at solutions. Keep track of mistakes and revisit them.

## Topics

- [Calculus](./calculus/README.md) — limits, derivatives, integrals, applications, differential equations, exam practice, and modelling.
- [AI Engineering — Machine Learning & Neural Networks](./ai-neural-networks/README.md) — mathematics foundations, machine learning, neural-network layers, forward propagation, backpropagation, CNNs, Transformers, and a Python project.
- Algebra — coming soon
- Geometry — coming soon
- Trigonometry — coming soon
- Statistics and Probability — coming soon
- Vectors and Matrices — coming soon

## How every topic should teach

1. Intuition and plain-language explanation
2. Definitions, notation, and formulas
3. Fully worked examples with every important step
4. Common mistakes and how to avoid them
5. Guided practice, independent questions, and answers
6. Exam-style strategy and real-world applications

**Understand first; memorize second.** This repository is educational and does not guarantee exam results. Consistent practice and feedback matter.
