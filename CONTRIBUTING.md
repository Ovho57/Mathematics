# Contributing

Help make mathematics understandable and accurate.

## Contributions welcome

- Fix errors and confusing explanations.
- Add original worked examples, exercises, diagrams, and exam-style questions.
- Add real-world applications with assumptions and units.
- Improve navigation and accessibility.

## Writing standards

- Explain the idea before the formula when possible.
- Define symbols and variables.
- Show intermediate steps—especially algebra.
- Verify answers independently.
- Use respectful language; never shame learners.
- Write original explanations and cite reliable sources when needed.
