# Lesson 2 — Algebra: Variables, Expressions, and Equations

Algebra lets us describe calculations without knowing every number in advance. Neural networks use algebra to express relationships between inputs, weights, biases, and outputs.

## 1. Variables

A variable is a symbol representing a number.

Example: `x + 3`

If x = 4:

`x + 3 = 4 + 3 = 7`

Variables allow one formula to work for many values.

## 2. Expressions versus equations

An **expression** is a calculation: `2*x + 5`.

An **equation** says two quantities are equal: `2*x + 5 = 13`.

## 3. Solve by undoing operations

Solve:

`x + 4 = 10`

Subtract 4 from both sides:

`x + 4 - 4 = 10 - 4`

Therefore:

`x = 6`

Solve:

`3*x = 18`

Divide both sides by 3:

`x = 6`

Solve:

`2*x + 5 = 17`

Step 1: subtract 5:

`2*x = 12`

Step 2: divide by 2:

`x = 6`

## 4. Why do we do the same operation on both sides?

An equation is like a balanced scale. If both sides are equal, changing both sides by the same amount preserves equality.

For example:

`x + 2 = 8`

Subtract 2 from both sides, not just one side.

## 5. Rearranging formulas

Suppose:

`y = 3*x + 2`

If y = 14, find x.

`14 = 3*x + 2`

Subtract 2:

`12 = 3*x`

Divide by 3:

`x = 4`

## 6. Algebra in a neuron

A simple neuron uses:

`z = w*x + b`

where:
- x is the input,
- w is the weight,
- b is the bias,
- z is the result before activation.

Example: x=3, w=2, b=1.

`z = 2*3 + 1 = 7`

If x changes to 4:

`z = 2*4 + 1 = 9`

The formula stays the same; the input changes.
