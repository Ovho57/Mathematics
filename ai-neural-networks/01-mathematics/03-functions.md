# Lesson 3 — Functions and Graphs

A function is a rule that takes an input and produces an output.

We write:

`y = f(x)`

Read this as “y equals f of x.”

## 1. Example function

Let:

`f(x) = 2*x + 1`

If x=3:

`f(3) = 2*3 + 1 = 7`

If x=0:

`f(0) = 2*0 + 1 = 1`

A function can be viewed as a machine:

Input x → function rule → output y

## 2. Input and output

For `f(x)=x^2`:
- input 2 gives output 4,
- input 3 gives output 9,
- input -3 gives output 9.

Different inputs can sometimes produce the same output.

## 3. Graphs

A graph shows input-output relationships.

- x-axis: input
- y-axis: output

For `y=2*x+1`, points include:
- x=0, y=1
- x=1, y=3
- x=2, y=5

Plot these points and connect them with a straight line.

## 4. Slope

Slope measures how much y changes when x changes.

`slope = change in y / change in x`

For `y=2*x+1`, the slope is 2. Whenever x increases by 1, y increases by 2.

For `y=-3*x+4`, the slope is -3. Whenever x increases by 1, y decreases by 3.

## 5. Functions in AI

A neural network is a composition of functions. One layer transforms input into a new representation; the next layer transforms that representation again.

A simple model might be:

`prediction = f(x)`

A larger network might be:

`prediction = f3(f2(f1(x)))`

Each stage processes the output of the previous stage.
