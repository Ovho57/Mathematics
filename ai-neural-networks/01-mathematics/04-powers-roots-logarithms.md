# Lesson 4 — Powers, Roots, and Logarithms

## 1. Powers

A power represents repeated multiplication.

`2^3 = 2*2*2 = 8`

The base is 2; the exponent is 3.

Examples:
- `5^2 = 25`
- `10^3 = 1000`
- `x^2 = x*x`

## 2. Useful power rules

For the same base:

`x^a * x^b = x^(a+b)`

Example:

`2^3 * 2^2 = 2^5 = 32`

Division:

`x^a / x^b = x^(a-b)` (when x is not zero)

Example:

`3^4 / 3^2 = 3^2 = 9`

Zero exponent:

`x^0 = 1` for x != 0.

## 3. Square roots

A square root asks: “What number multiplied by itself gives this?”

`sqrt(25) = 5`, because `5*5=25`.

## 4. Logarithms

A logarithm answers the reverse question of exponentiation.

`log_2(8)=3`

because:

`2^3=8`

Another example:

`log_10(100)=2`

because:

`10^2=100`

## 5. Why logarithms appear in AI

Logarithms are useful for:
- measuring probabilities,
- loss functions,
- numerical stability,
- and understanding exponential growth.

For example, cross-entropy loss uses the negative logarithm of the probability assigned to the correct answer. A model is penalized when it gives the correct answer a very small probability.
