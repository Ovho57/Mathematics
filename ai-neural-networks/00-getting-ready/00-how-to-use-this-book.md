# Lesson 0.0 — How to Use This Book

## Welcome

This book is your guide to the mathematics behind artificial intelligence and neural networks. It is written for learners who want to understand how AI works deeply enough to build it—not simply copy code from a tutorial.

You may have heard terms such as *matrix*, *derivative*, *gradient*, *weight*, or *backpropagation*. Some of them may sound difficult. That is normal. We will introduce each idea carefully, explain its meaning, and connect it to neural networks.

## The goal is understanding

There are three levels of learning:

1. **Recognize:** You have seen a formula before.
2. **Use:** You can apply the formula to a problem.
3. **Understand:** You can explain why it works, when to use it, and what it means.

This book aims for the third level.

## Four ways to learn each concept

### 1. Intuition
First, understand the idea in ordinary language. For example, a derivative tells us how quickly something changes.

### 2. Mathematics
Next, learn the symbols and formulas. Symbols are a compact way to express ideas—not a different language designed to scare you.

### 3. Worked examples
Follow calculations line by line. Never skip a step just because a textbook says it is obvious.

### 4. Code
Finally, use Python to check the mathematics. Code is a way to experiment with ideas, not a replacement for understanding them.

## A useful study routine

For each lesson:

- Read the explanation once.
- Read it again while writing down important ideas.
- Solve the worked example yourself.
- Complete the practice questions without looking at the solution.
- Write a short explanation in your own words.
- Test the idea with a tiny Python program when appropriate.

If you get stuck, identify the exact step that confuses you. Review the prerequisite instead of memorizing the answer.

## What mathematics do neural networks use?

A neural network is a mathematical function with adjustable parameters. It takes input data, performs calculations, and produces an output.

The central mathematical tools are:

- **Algebra:** expressions, equations, and rearranging formulas.
- **Functions:** mapping inputs to outputs.
- **Vectors and matrices:** representing data and performing many calculations efficiently.
- **Probability and statistics:** reasoning about data and uncertainty.
- **Calculus:** measuring how outputs change when parameters change.
- **Optimization:** adjusting parameters to reduce errors.

You will learn these in a sensible order.

## You do not need to be a genius

Mathematics is a skill. It improves through practice, feedback, and patience. Confusion is not proof that you cannot learn a topic; it is a signal to slow down and find the missing step.
