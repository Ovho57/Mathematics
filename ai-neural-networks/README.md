# Mathematics for AI and Neural Networks
## From zero to understanding and building neural networks

This book teaches the mathematics behind AI step by step, with the goal of understanding the formulas and implementing neural networks in Python.

## Start here

**[Read the complete textbook](./FULL-TEXTBOOK.md)** — includes arithmetic, algebra, functions, vectors, matrices, probability, statistics, calculus, gradient descent, neurons, layers, forward propagation, loss, backpropagation, and Python implementation.

### Important equation formatting note
Equations are written in plain-text/code notation to make them readable on GitHub, phones, and other Markdown viewers. For example:

`z = w1*x1 + w2*x2 + b`

means multiply each input by its matching weight, add all products, then add the bias. The `*` symbol means multiplication; `**` means exponent; `sqrt(x)` means square root.
