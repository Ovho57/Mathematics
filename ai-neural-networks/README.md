# AI Engineering — Machine Learning & Neural Networks

Welcome to a complete learning path for understanding the mathematics and engineering behind AI, neural networks, and modern deep learning.

**This is a textbook, not a list of topics.** Lessons explain ideas in plain English, show calculations line by line, include examples, and give you practice.

## Math display rule

All calculations use plain-text notation for reliable GitHub display:

- Multiplication: `3*x` or `3 × x`
- Division: `a/b`
- Powers: `x^2`
- Square root: `sqrt(x)`
- Subscript: `x_1`, `w_2`
- Summation: `sum(i=1 to n) of x_i`

## How to study

1. Read each lesson slowly.
2. Copy examples and calculate each step yourself.
3. Do exercises before checking answers.
4. Do not skip math foundations: neural networks are built from these ideas.
5. Use Python only after you understand what the calculation means.

## The learning path

Arithmetic → algebra → functions → vectors → matrices → probability → calculus → machine learning → neurons → layers → forward propagation → loss → backpropagation → training → deep learning → Transformers.

You do not need to know everything before beginning. Learn one lesson at a time.

## Learning promise

The goal is not memorizing formulas. The goal is to understand:
- what each quantity means,
- why the operation is performed,
- how the result is calculated,
- how that calculation appears in code,
- and how the parts combine into a learning system.
